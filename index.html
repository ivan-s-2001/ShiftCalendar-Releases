В приложении

График, который удобно открыть на ходу

Приложение рассчитано на сотрудников, у которых уже есть доступ к рабочей таблице. Оно не редактирует смены и не записывает ничего в исходную Google Таблицу.

01

Календарь и список

Месяц, неделя и список дней используют одну палитру смен. Рабочие выходные, переработки и ночные смены различаются цветом.

02

Виджеты Android

Представление выбирается при добавлении виджета. После этого оно перекомпоновывается под доступный размер и показывает больше деталей на крупных сетках.

03

Заметки и напоминания

Личные записи привязаны к датам. Напоминания работают на устройстве, а копия заметок может синхронизироваться через приватное хранилище приложения в Google Drive.

Google OAuth

Доступ запрашивается только для функций приложения

Авторизация нужна, чтобы проверить доступ пользователя к рабочей таблице, прочитать расписание и синхронизировать личные заметки. Пароль Google приложение не получает.

Google Sheets: только чтение

https://www.googleapis.com/auth/spreadsheets.readonly

Приложение читает только заранее заданную рабочую таблицу и отображает график. Оно не перечисляет другие таблицы пользователя, не даёт выбирать произвольные файлы, не создаёт, не изменяет и не удаляет таблицы или их содержимое.

Google Drive: только данные приложения

https://www.googleapis.com/auth/drive.appdata

Используется закрытая папка appDataFolder для личных заметок и напоминаний. Этот доступ не позволяет просматривать обычные файлы пользователя в Google Drive.

Google API Services User Data — Limited Use Использование информации, полученной через Google Workspace API, соответствует Google API Services User Data Policy, включая требования Limited Use. Данные Google используются только для функций, которые пользователь видит в приложении; они не продаются, не передаются рекламным системам и не используются для обучения общих моделей ИИ.

Установка

Первый APK ставится вручную. Дальше приложение обновляет себя само.

1

Скачайте APK

Android может попросить разрешить установку приложений из браузера. Это стандартное системное разрешение.

2

Войдите через Google

Используйте аккаунт, которому уже открыт доступ к рабочей таблице. Приложение проверит доступ реальным запросом.

3

Получайте обновления

Новая версия проверяется не чаще одного раза в 12 часов. Перед установкой приложение сверяет SHA-256, package name, versionCode и сертификат подписи.
