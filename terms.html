Условия использования

Эти условия относятся к Android-приложению «График СЗ» и публичному сайту приложения.

1. Назначение

«График СЗ» — некоммерческое приложение для просмотра рабочего расписания, доступного пользователю через Google Sheets, а также для личных заметок и напоминаний. Приложение не является системой кадрового учёта и не изменяет исходное расписание.

2. Доступ

Для просмотра рабочего графика нужен Google-аккаунт, которому владелец рабочей таблицы уже предоставил доступ. Пользователь отвечает за использование подходящего аккаунта и соблюдение правил своей организации.

3. Google APIs

Использование Google Sheets и Google Drive регулируется также условиями Google. Приложение запрашивает только разрешения, описанные в Политике конфиденциальности.

4. Обновления

APK распространяется через GitHub Releases. Приложение может проверять наличие новой версии и предлагать установку подписанного APK. Системный установщик Android всегда показывает пользователю отдельное подтверждение установки.

5. Доступность сервиса

Работа приложения зависит от Android, Google OAuth, Google Sheets, Google Drive, GitHub и доступности рабочей таблицы. Временные ошибки сторонних сервисов могут влиять на синхронизацию и обновления. Офлайн-кеш не гарантирует наличие самых свежих данных.

6. Точность расписания

Источником расписания остаётся рабочая Google Таблица. Если данные в приложении расходятся с официальным графиком организации, следует ориентироваться на источник, принятый в организации, и обновить данные приложения.

7. Отказ от гарантий

Приложение предоставляется «как есть» для удобного просмотра графика. Разработчик не обещает непрерывную работу сторонних сервисов и не несёт ответственности за решения, принятые только на основании устаревшего офлайн-кеша или данных, ошибочно внесённых в исходную таблицу.

8. Изменения

Условия могут обновляться вместе с функциональностью приложения. Актуальная версия всегда опубликована на этой странице.

9. Контакт

Вопросы по приложению: falseheat@gmail.com.

English summary

Grafik SZ is a non-commercial Android application for viewing a work schedule from a Google Sheet available to the user and for keeping private notes and reminders. The app does not modify the source schedule. Availability depends on Android, Google and GitHub services. The app is provided as-is for convenience.
