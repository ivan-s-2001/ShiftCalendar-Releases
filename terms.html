Внутреннее использование

Условия использования

«График СЗ» предназначен для внутреннего использования сотрудниками компании.

Назначение

Приложение помогает просматривать рабочий график, использовать виджеты, заметки и напоминания. Источником расписания остаётся рабочая система компании.

Доступ

Для работы может потребоваться корпоративный Google-аккаунт с необходимыми правами доступа.

Обновления

Новые версии распространяются в виде подписанных APK через эту страницу и встроенный механизм обновления приложения.
