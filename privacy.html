Политика конфиденциальности

Эта политика относится к Android-приложению «График СЗ» и объясняет, какие данные оно получает через Google OAuth, зачем они нужны и где хранятся.

Разработчик: ivan-s-2001. Контакт по вопросам конфиденциальности: falseheat@gmail.com.

1. Что делает приложение

«График СЗ» показывает рабочее расписание из заранее заданной Google Таблицы. Пользователь входит через Google-аккаунт, которому уже предоставлен доступ к этой таблице. Приложение также позволяет вести личные заметки и напоминания и синхронизировать их через закрытую папку данных приложения в Google Drive.

Приложение не предоставляет разработчику отдельный сервер для хранения расписания, заметок или OAuth-данных. Запросы к Google выполняются с устройства пользователя.

2. Доступ к данным Google

Google Sheets

https://www.googleapis.com/auth/spreadsheets.readonly

Этот scope нужен для чтения рабочей Google Таблицы и отображения расписания в приложении. Хотя Google описывает этот scope как доступ на чтение таблиц, приложение обращается только к заранее заданному ID рабочей таблицы: оно не перечисляет другие таблицы пользователя и не даёт выбирать произвольные файлы. Приложение не изменяет, не создаёт и не удаляет Google Таблицы. Из полученных данных формируется календарь смен; часть расписания сохраняется локально на устройстве для офлайн-просмотра.

Google Drive appDataFolder

https://www.googleapis.com/auth/drive.appdata

Этот scope используется только для синхронизации личных заметок и напоминаний через специальную папку appDataFolder, доступную приложению. Он не даёт приложению доступ к обычным документам, фотографиям или другим файлам пользователя в Google Drive.

Данные аккаунта

Приложение может сохранять на устройстве адрес выбранного Google-аккаунта и имя выбранного сотрудника, чтобы восстановить сеанс и показать нужный график. Пароль Google приложение не получает и не хранит.

3. Как используются данные

Данные Google используются только для функций, видимых пользователю в приложении:

  • проверка, что выбранный аккаунт имеет доступ к рабочей таблице;
  • чтение и отображение рабочего расписания;
  • создание офлайн-кеша расписания на устройстве;
  • синхронизация личных заметок и напоминаний через Google Drive appDataFolder.
Limited Use Использование информации, полученной через Google Workspace API, соответствует Google API Services User Data Policy, включая требования Limited Use. Данные Google не продаются, не используются для рекламы, кредитного скоринга или обучения общих моделей машинного обучения/ИИ и не передаются брокерам данных.

4. Где хранятся данные

Кеш расписания, настройки, выбранный аккаунт и локальная копия заметок хранятся на устройстве в приватном хранилище Android. Синхронизированные заметки также могут находиться в appDataFolder Google Drive пользователя. Разработчик не получает копию этих данных на собственный сервер.

5. Передача третьим лицам

Приложение не продаёт и не передаёт данные Google рекламным сетям, аналитическим платформам, брокерам данных или другим третьим лицам. Google получает запросы в рамках своих API, необходимых для авторизации, чтения таблицы и синхронизации appDataFolder.

Для проверки обновлений приложение обращается к публичному GitHub API и скачивает APK из GitHub Releases. Данные, полученные из Google Sheets или Google Drive, в GitHub не отправляются.

6. Аналитика и реклама

В приложении нет рекламных SDK и сторонней продуктовой аналитики. Сайт приложения также не использует рекламные пиксели, сторонние шрифты или аналитические трекеры.

7. Удаление данных и отзыв доступа

  • Удаление заметки в приложении синхронизирует удаление с appDataFolder, когда доступ к Google Drive доступен.
  • Выход из аккаунта очищает локальные данные аккаунта, кеш расписания и локальные заметки на устройстве.
  • Пользователь может в любой момент отозвать доступ приложения к Google-аккаунту в настройках безопасности Google.
  • Удаление приложения или очистка его данных Android удаляет локальную копию данных.

Данные, уже сохранённые в Google Drive appDataFolder, принадлежат аккаунту пользователя и могут сохраняться после выхода из приложения. Для полного удаления синхронизированных заметок их следует удалить в приложении до отзыва доступа либо удалить данные приложения в настройках Google Drive/Google Account, если такая функция доступна для аккаунта.

8. Безопасность

Авторизация выполняется через Google OAuth. Приложение запрашивает только scopes, необходимые для расписания и синхронизации заметок. APK обновлений подписывается тем же release-сертификатом; перед запуском системного установщика приложение проверяет SHA-256, package name, versionCode и сертификат подписи скачанного APK.

9. Изменения политики

Если способ использования данных Google изменится, эта политика будет обновлена до выпуска версии приложения, использующей новые данные или новые цели обработки.

10. Контакт

Вопросы о данных и запросы, связанные с конфиденциальностью: falseheat@gmail.com.

English summary

Grafik SZ uses Google Sheets read-only access to display a work schedule and Google Drive appDataFolder access to sync the user's private notes and reminders. Google user data is used only for these user-facing features. It is not sold, used for advertising, transferred to data brokers, or used to train general AI/ML models. Schedule data and notes are handled on the user's device and in the user's Google account; the developer does not operate an application server that stores this Google user data.
