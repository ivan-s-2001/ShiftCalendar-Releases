Политика конфиденциальности

«График СЗ» — внутреннее Android-приложение для сотрудников компании.

Какие данные использует приложение

Для входа и работы с расписанием приложение использует Google OAuth. Доступ к Google Sheets применяется только для чтения рабочего расписания, доступного выбранному пользователю.

Google Drive appDataFolder используется только для синхронизации личных заметок и напоминаний приложения. Обычные файлы Google Drive приложение не просматривает.

Как используются данные

Данные используются только для функций приложения: отображения рабочего графика, офлайн-доступа к нему и синхронизации заметок и напоминаний. Данные не продаются, не используются для рекламы и не передаются рекламным системам.

Передача данных

Данные рабочего расписания, заметок и напоминаний не передаются рекламным системам, брокерам данных или другим сторонним сервисам. Запросы выполняются только к Google API, необходимым для работы этих функций.

Хранение и удаление

Часть данных хранится локально на устройстве. Синхронизированные заметки могут храниться в закрытой области Google Drive, предназначенной для данных приложения. Пользователь может выйти из аккаунта, удалить локальные данные приложения и отозвать доступ приложения в настройках Google-аккаунта.

Google API Services User Data

Использование данных, полученных через Google APIs, соответствует Google API Services User Data Policy, включая требования Limited Use.
